# 홈을 실제 최신 글 목록으로 표시한다

작성: 2026-11-02
상태: 앞서 제안한 최신순·인기 영역 제거를 구현·배포했고 frontend65개 gate와 공개 홈에서 확인했다.

## 문제와 결정

홈은 importanceScore 상위3개를 Popular로, 나머지 전체를 Today's Important News로 표시한다.
날짜 제한·조회수 집계가 없어 두 제목 모두 실제 의미와 다르다. 현재 표시 기준을 정리한다.

- 홈은 ‘최신 글’ 한 영역에 전체 목록을 게시일 내림차순으로 표시한다.
- 게시 시각은 ISO timezone을 포함한 실제 시각으로 비교하며 동률이면 기사 ID 내림차순이다.
- 점수는 홈 정렬에 쓰지 않는다. 날짜를 오늘로 제한하거나 오래된 글을 삭제하지 않는다.
- 검색 결과의 관련도 순서는 서버 응답 그대로 유지하고 홈 정렬은 배열 복사본에만 적용한다.
- 캐시·검색·로딩/오류/빈 상태·기존 요약·출처 registry·비용 설정은 유지한다.
- 한글 제목과 관계없는 안정적인 heading ID로 접근성 연결을 유지한다.

숫자 기준 없는 인기 영역은 제거한다. 출처 범위·데모 기사 노출·페이지 구분은 별도 정책으로
남기며 이번에 임의로 출처를 끄거나 데이터를 지우지 않는다. 추가 AI 호출은 필요 없다.

## 검증

높은 점수의 오래된 기사보다 낮은 점수의 새 기사가 먼저 나오는지, 동일 시각/서로 다른
UTC offset의 날짜 정렬, 검색 관련도 순서·원본 배열·캐시 상태 보존을 UI 테스트로 검증한다.
frontend test/lint/build 후 web image만 배포하고 public home과 HTTP smoke를 확인한다.
backend/AI 코드는 바꾸지 않으므로 해당 suite를 재실행하지 않는다.
