# 2026-06-09 개발 로그: 포트폴리오 문서 리뷰 지적 정리

## 요약

오늘은 2026-06-08 포트폴리오 문서 refresh에 대한 리뷰 지적을 정리했다.
새 기능이나 새 benchmark 결과를 만들지 않고, 문서 안의 숫자 오기와 ROADMAP/STATUS 사이의 다음 작업 불일치를 바로잡았다.
또 리뷰용으로 생성했던 `.understand-anything/` 산출물과 unreviewed draft label이 PR scope에 들어가지 않도록 로컬 Git exclude를 정리했다.

## 오늘 완료한 일

- `docs/superpowers/plans/2026-06-08-portfolio-demo-docs-refresh.md`
  - smoke baseline의 query/article 수 오기를 `3-query/6-article smoke baseline`으로 수정했다.
- `docs/ROADMAP.md`, `docs/ROADMAP.ko.md`
  - 현재 다음 작업을 이미 생성된 `api-ready-2026-06-05` 41-article expanded catalog 기준으로 맞췄다.
  - 다음 benchmark 작업을 catalog 확장이 아니라 reviewed label handoff, 10-15 query label set, expanded comparison rerun으로 정리했다.
  - 실제 수정일에 맞춰 `Last updated`를 2026-06-09로 갱신했다.
- PR scope 정리
  - 리뷰용 `.understand-anything/` 산출물을 제거했다.
  - `.git/info/exclude`에 `.understand-anything/`와 `experiments/datasets/labels/search-labels.api-ready-2026-06-05.draft.json`를 추가해 PR에 실수로 포함되지 않게 했다.

## 설계 고민 / 결정

`api-ready-2026-06-05` 41-article catalog는 이미 존재한다.
따라서 ROADMAP의 다음 작업을 "6개 article catalog를 더 확장한다"로 두면 현재 STATUS와 충돌한다.
지금 필요한 일은 catalog 생성이 아니라 reviewed label을 확보하고, 그 label이 생긴 뒤 expanded benchmark를 다시 실행하는 것이다.

draft label은 삭제하지 않았다.
아직 사람이 검토하지 않은 작업물이라 PR에 들어가면 안 되지만, 다음 라벨링 handoff의 참고 자료일 수 있으므로 local exclude로만 scope를 차단했다.

## 트레이드오프

- 얻은 것: PLAN, ROADMAP, STATUS가 같은 기준으로 `3-query/6-article smoke`와 `41-article expanded catalog`를 설명한다.
- 얻은 것: 리뷰용 분석 산출물과 draft label이 PR status에서 사라져 commit scope가 더 명확해졌다.
- 미룬 것: Docker runtime smoke, backend/frontend/AI test suite, expanded benchmark 실행은 이번 문서 리뷰-fix 범위에서 하지 않았다.

- Docker Compose 기반 collection/projection/search/graph runtime smoke는 이번 세션에서 재실행하지 않았다.
- Backend `./gradlew test`, frontend `npm test/lint/build`, AI pytest는 문서 리뷰-fix 범위라 실행하지 않았다.
- 41-article expanded benchmark는 reviewed label이 없어서 실행하지 않았다.
