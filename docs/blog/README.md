# Sigak Development Blog

이 디렉터리는 두 종류의 글을 다룬다.

1. **dev-log** (`YYYY-MM-DD-dev-log.md`): 매일 구현한 것을 기록하는 일일 로그. 성실성 공개 + 나중 주제 선정용 근거 저장소.
2. **주제형 기술 블로그** (예: `2026-05-28-flyway-adoption.md`): topic-queue에 쌓인 후보 중 하나를 골라 한 주제만 깊게 쓴 포트폴리오용 글.
